Codeply 4.0 on Rune: beta
=========================

Install
- Run Codeply-Setup.exe. It installs Codeply for you (no admin needed) with its own engine (DSH,
  Node and codeply-cli), adds Start menu and desktop shortcuts, and opens Codeply.
- Or unzip Codeply-Rune-windows-x64.zip anywhere and run Codeply.exe: the same app, with the
  engine in the "resources" folder beside it.
- Nothing else to install. Sign in from Settings > Account with your Codeply email.

Updating
Run the newer Codeply-Setup.exe. It closes Codeply, replaces it, and keeps your chats and settings.

Where things are
- New chats work in the folder %USERPROFILE%\Codeply (made on first run).
- Chats and settings are kept in %USERPROFILE%\.codeply\rune; the engine's log is there too
  (engine.log).
- Uninstall from Windows Settings > Apps > Codeply. Your data in %USERPROFILE%\.codeply stays.

If a reply says you're not signed in
Open Settings > Account and sign in, then send again.

If the window doesn't open
Codeply draws on the CPU, so any Windows 10 or 11 PC works. Check engine.log (above) and send it
to us.
