# Product

## Register

product

## Users

Developers using Codeply Craft at a desktop workstation who occasionally need to start, observe, steer, or approve an agent run from a phone. Their priority is trustworthy visibility into work running on their own PC, not a cramped copy of the desktop IDE.

## Product Purpose

Codeply Craft is a local-first AI coding agent. Its mobile companion dispatches work to the desktop app, streams its progress, and keeps destructive actions behind a deliberate approval decision.

## Brand Personality

Calm, capable, precise. The product should feel like a quiet control surface for serious work, never a noisy social chat or a toy remote.

## Anti-references

Avoid a shrunken desktop dashboard, decorative neon cyberpunk, opaque "autopilot" actions, and dense notification-feed patterns that conceal what the agent is doing.

## Design Principles

- Make the active desktop run unmistakable at a glance.
- Let a phone start work in one focused gesture.
- Explain consequential actions before asking for approval.
- Preserve context across devices without copying desktop complexity.
- Treat connection state and local execution as first-class information.

## Accessibility & Inclusion

Meet WCAG AA contrast, retain system text sizing, provide visible keyboard focus, and respect reduced-motion preferences. Never convey run state or approval risk through color alone.
