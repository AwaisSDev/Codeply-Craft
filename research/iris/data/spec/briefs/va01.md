## Focus for this shard

Cover everything in spec §3. In addition, go deeper on:

* look-alike people and projects (shared first names, near-identical project names); facts must attach to the right one

## Working method

1. Write 3-4 episodes, append them to the file, run the validator (`--split val`), fix the errors, then continue. Appending in small batches keeps mistakes cheap.
2. Vary everything: session length, tone, how facts are phrased, where in a message they sit, which source carries them. Avoid a house style; no two episodes should feel written by the same hand.
3. Keep dates coherent: weekdays must match the calendar (2026-01-05 is a Monday; 2027-01-04 is a Monday).
4. When you are done, run the validator once more and report its summary line, the number of episodes, and anything you were unsure about. Do not write any other files.
